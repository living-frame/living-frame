# מסגרת חיה

אפליקציית AR שמזהה תמונות על קירות בית הכנסת ומריצה עליהן הנפשה, צמודה למסגרת ובזווית שממנה מסתכלים.
אין שרת ואין בילד: גיטהאב הוא גם האחסון וגם מסד הנתונים.

## איך זה בנוי

```
גיטהאב  ──  manifest.json   רשימת הפריטים: שם, מיקום, הקדשה, שמות קבצים, rev
        ──  targets.mind    כל התמונות דחוסות לקובץ זיהוי אחד
        ──  media/          התמונות והסרטונים
             ▲                        │
             │ כותב בפרסום            │ מוריד לפי דרישה
        admin.html                index.html
        (מסך גבאי)                (הטלפון)
```

הטלפון מוריד בפתיחה רק את `manifest.json` ואת `targets.mind`. סרטון יורד בפעם הראשונה
שהתמונה שלו זוהתה, ואז נשמר ב־IndexedDB של המכשיר — בפעם הבאה הוא נפתח מיידית וגם בלי רשת.
במסך הפתיחה יש כפתור להורדת הכול מראש.

השדה `rev` בכל פריט הוא מספר הגרסה שלו. החליפו סרטון — ה־rev משתנה, והטלפון מוריד את החדש
במקום להישאר עם הישן. עותקים ישנים נמחקים מהמכשיר לבד.

## הקבצים

| קובץ | מה זה |
|---|---|
| `index.html` | האפליקציה למתפלל |
| `admin.html` | מסך הגבאי — קורא מגיטהאב, כותב לגיטהאב |
| `sw.js` | Service worker: שומר את שלד האפליקציה והספריות למצב לא־מקוון |
| `manifest.json` | רשימת הפריטים |
| `targets.mind` | מאגר המטרות. כרגע מכיל את תמונת האריה (ציון 72) |
| `media/` | התמונות והסרטונים |
| `app.webmanifest` | כדי שאפשר יהיה להוסיף למסך הבית |
| `compile.mjs` | בניית `targets.mind` משורת פקודה, כחלופה למסך הגבאי |

## העלאה ל־GitHub Pages

```bash
git init && git add . && git commit -m "living frame"
git branch -M main
git remote add origin https://github.com/<user>/living-frame.git
git push -u origin main
```

Settings → Pages → Deploy from a branch → `main` / `(root)`.
המתפללים: `https://<user>.github.io/living-frame/` · הגבאי: אותה כתובת עם `/admin.html`.

חובה HTTPS — בלעדיו אין גישה למצלמה. GitHub Pages נותן את זה לבד.
הריפו חייב להיות ציבורי כדי ש־Pages החינמי יפרסם אותו.

## מסך הגבאי

1. **חיבור** — שם משתמש, שם ריפו, וטוקן אישי עם הרשאת Contents: write
   (‏GitHub → Settings → Developer settings → Personal access tokens → Fine-grained,
   בוחרים את הריפו ונותנים Contents: Read and write). הטוקן נשמר בדפדפן הזה בלבד.
2. **הוספת פריט** — גוררים תמונה וסרטון, ממלאים שם, מיקום והקדשה.
   "בדיקת איכות זיהוי" מחזירה מספר נקודות עוגן: מעל 40 יציב, 20–40 גבולי, מתחת ל־20 לא מומלץ.
3. **פרסום** — מעלה את הקבצים החדשים, מוריד את תמונות המקור הקיימות מגיטהאב, בונה מחדש את
   `targets.mind` (כ־15 שניות לתמונה) וכותב `manifest.json` חדש.

המסך לא מחזיק מאגר משלו: מה שרואים בו הוא מה שבאמת מפורסם. אפשר לעבוד מכל מחשב.
רק פריטים שנוספו ועדיין לא פורסמו נשמרים זמנית בדפדפן, כדי שרענון לא יאבד סרטון שגררת.

## איפה לאחסן את הסרטונים

התנאי היחיד: השרת שמגיש את הסרטון חייב להחזיר `Access-Control-Allow-Origin`.
הווידאו נטען כטקסטורה של WebGL, ובלי הכותרת הזאת הדפדפן פוסל אותו ומופיע מלבן שחור.
**וואן־דרייב, גוגל דרייב ודרופבוקס לא מחזירים אותה** — הם לא מתאימים כאן, גם עם קישור "ישיר".

| אפשרות | מגבלות | מתי |
|---|---|---|
| GitHub Pages (ברירת מחדל) | אתר עד 1 ג׳יגה, ‏100 ג׳יגה תעבורה בחודש (soft) | כמעט תמיד |
| jsDelivr מעל אותו ריפו | 20 מגה לקובץ, מטמון של 12 שעות על ענף | כשרוצים להוריד עומס מגיטהאב |
| Cloudflare R2 / Supabase / Backblaze B2 | דורש הגדרת CORS ידנית | מאות סרטונים או קבצים כבדים |

בוחרים במסך הגבאי תחת "מאיפה הטלפונים ימשכו את הסרטונים". הבחירה נשמרת בשדה `cdn` שב-`manifest.json`,
והאפליקציה מכבדת גם כתובת מלאה בשדה `video` של פריט בודד.

**לפני שמחפשים אחסון — לבדוק משקל.** קליפ של 10 שניות ב-720×1280 צריך לשקול מגה עד שניים.
הקובץ המקורי כאן היה 6 מגה (4.7 מגהביט לשנייה, מקודד בבזבזנות) והוקטן ל-1.7 מגה בלי הבדל נראה לעין:

```bash
ffmpeg -i in.mp4 -c:v libx264 -crf 26 -preset slow \
  -vf scale=914:1280 -movflags +faststart -c:a aac -b:a 64k out.mp4
```

ה-`scale` גם מיישר את יחס הסרטון ליחס התמונה, כך שלא צריך לחתוך כלום בתצוגה.

## בדיקה מקומית

```bash
python -m http.server 8000
```
`http://localhost:8000` נחשב מקור מאובטח, אז המצלמה עובדת גם בלי HTTPS.
מסך הגבאי יעבוד גם מקומית — הוא פונה לגיטהאב ישירות דרך ה־API.

## הוספת תמונות משורת פקודה (חלופה)

```bash
npm init -y && npm pkg set type=module
npm install mind-ar@1.2.5 jpeg-js pngjs --ignore-scripts
node compile.mjs media/lion.jpg media/tzadik.jpg
```
הסדר בשורת הפקודה הוא ה־`index` ב־`manifest.json`, וחייב להתאים.

## כשמשהו לא מתנהג

| מה קורה | למה | מה עושים |
|---|---|---|
| לא נועל בכלל | התמונה המודפסת שונה מהקובץ שממנו נבנה המאגר | לצלם את התמונה כפי שהיא תלויה ולפרסם מחדש |
| נועל ומשחרר | תאורה חלשה או בוהק מזכוכית | להזיז תאורה, או להוריד `filterMinCF` ב־`index.html` |
| רועד | הפילטר עדין מדי | `filterBeta` נמוך יותר = יציב יותר, מגיב לאט יותר |
| הסרטון לא מתחיל | ההורדה הראשונה עדיין רצה | פס ההתקדמות מופיע מתחת לכרטיס. אפשר להוריד הכול מראש ממסך הפתיחה |
| הטלפון מציג גרסה ישנה | ה־service worker מגיש מטמון | לרענן פעמיים, או לפתוח עם `?v=2` |
| שגיאה 403 בפרסום | לטוקן אין הרשאת כתיבה על הריפו | ליצור טוקן חדש עם Contents: Read and write |
